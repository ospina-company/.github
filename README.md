# .github

Org-level defaults for `ospina-company`.

`profile/README.md` renders as the organization front door at
<https://github.com/ospina-company>. It is visible to every org member, so
treat edits to it as outward-facing copy: house prose rules apply, and it gets
a humanizer pass before it ships.

Shared conventions live in [`handbook`](https://github.com/ospina-company/handbook).
